# Mayhemate

Веб-игра: шахматы с HP/атакой, системой темпа и картами. Поддерживает локальный режим и онлайн-матчи по P2P (PeerJS).

## Стек

- JavaScript (ES modules), Phaser 4
- Vite 8 (dev/build/preview)
- Vitest 5 (тесты)
- PeerJS 1.5 (онлайн)

## Требования

- Node.js >= 18 (проверено на v24)
- npm

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev          # dev-сервер Vite (по умолчанию http://localhost:5173)
npm run build        # production-сборка в dist/
npm run preview      # предпросмотр сборки
```

## Тесты

```bash
npm test             # vitest run (одноразовый прогон)
```

## Генерация ассетов карт

```bash
npm run cards:assets # пересоздаёт PNG-шаблоны карт в public/assets/cards
```

## Мультиплеер / TURN

Онлайн использует STUN/TURN. Свои TURN-серверы задаются через переменные окружения (префикс `VITE_`):

```bash
VITE_TURN_URLS=turn:host:3478
VITE_TURN_USERNAME=user
VITE_TURN_CREDENTIAL=pass
```

Без них используются встроенные публичные STUN/TURN.

## Структура

```
src/
  main.js              # точка входа Phaser
  game/                # логика: Game, GameSession, Piece, deck (карты), transport
  net/                 # PeerTransport, протокол
  render/              # BoardView, PieceView, CardView, cardFan и т.д.
  scenes/              # Home, Boot, Lobby, Game, BottomUi
public/assets/         # спрайты, аудио, шрифты, карты
scripts/               # генерация ассетов карт
```

## Управление

- Локальная игра: «Локально» на главном экране.
- Онлайн: «Создать игру» (код комнаты) / «Присоединиться» (ввод кода).
- Сессия сохраняется в `sessionStorage` и восстанавливается при перезагрузке (для host/guest).

## Правила (кратко)

- Шахматная доска 8×8, фигуры имеют HP и атаку.
- Ход: перемещение или атака; за ход можно сделать одно перемещение, атак — пока есть темп.
- Темп растёт с ходами (до 5).
- В начале матча у каждого игрока по 3 карты; в начале каждого следующего хода игрок добирает 1 карту (максимум 6 в руке, иначе добор не происходит).
- Разыгрыш карты стоит темпа: столько, сколько указано в стоимости карты (иконка темпа + цифра на карте).
- Карты играются перетаскиванием на клетку; недоступные по темпу затемнены.
- Смена хода — кнопка «Конец хода».

# Mayhemate — игровая логика (GAME_LOGIC)

Документ для проектирования карт. Описывает реальную логику, реализованную в коде (`src/game/*`). Ничего из кода не меняет.

## 1. Обзор

Веб-игра: шахматы 8×8, где у каждой фигуры есть HP и атака. Ход состоит из перемещений/атак и розыгрыша карт. Ключевой ресурс — **темп** (tempo), растущий со временем. Карты стоят темпа и разыгрываются перетаскиванием на клетку. Поддерживается локальный режим и онлайн P2P (host-authoritative).

## 2. Доска и координаты

- Размер: 8×8. Координаты `(col, row)`, где `col,row ∈ [0..7]`.
- Белые (`white`) начинают снизу: пешки на ряду 6, остальные фигуры на ряду 7.
- Чёрные (`black`) начинают сверху: пешки на ряду 1, остальные на ряду 0.
- Белые ходят вверх (уменьшение `row`), чёрные — вниз (увеличение `row`).
- Визуально доска может быть перевёрнута для чёрных, но логические координаты те же.

## 3. Фигуры

Начальная расстановка стандартная (ладья, конь, слон, ферзь, король, слон, конь, ладья; пешки перед ними). Характеристики:

| Тип | Имя | HP | Атака |
|---|---|---:|---:|
| pawn | Пешка | 2 | 1 |
| knight | Конь | 3 | 2 |
| bishop | Слон | 3 | 2 |
| rook | Ладья | 4 | 2 |
| queen | Ферзь | 4 | 3 |
| king | Король | 6 | 1 |

Каждая фигура имеет `id`, `type`, `col`, `row`, `color`, `hp`, `atk`. `hp`/`atk` могут меняться картами/эффектами (в коде есть `addHp`, `damage`, `addAtk`). Фигура удаляется при `hp <= 0`.

Особые шахматные правила **не реализованы**: нет рокировки, взятия на проходе, превращения пешки. Пешка остаётся пешкой на последней горизонтали.

## 4. Движение и атака

Ход делает сторона `turn` (`'white'` или `'black'`). Доступные действия:

- `MOVE` — перемещение или атака.
- `END_TURN` — завершить ход.
- `PLAY_CARD` — разыграть карту.

### 4.1 Правила ходов по типам

- **Пешка**: на 1 клетку вперёд, если клетка пуста; с начальной позиции — на 2 клетки, если обе пусты; атакует по диагонали вперёд на 1, только если там вражеская фигура.
- **Конь**: ход буквой «Г» (2+1), перепрыгивает фигуры.
- **Ладья**: по горизонтали/вертикали, путь должен быть свободен.
- **Слон**: по диагонали, путь свободен.
- **Ферзь**: ладья + слон.
- **Король**: на 1 клетку в любом направлении (включая взятие вражеской фигуры). Ограничений на ход под бой нет.

Нельзя ходить на клетку со своей фигурой; можно на клетку с вражеской — это атака.

### 4.2 Атака

При атаке атакующая фигура остаётся на месте, цель получает урон `attacker.atk`. Если `target.hp <= 0`, цель удаляется, а атакующая фигура **перемещается на клетку цели** (события `attack`, затем `kill` и `move`). Если цель выжила, атакующая фигура остаётся на исходной клетке (событие `attack`).

### 4.3 Ограничения за ход

- За весь ход можно сделать **не более одного перемещения на пустую клетку** (глобальный флаг `movedThisTurn`). После любого перемещения дальнейшие перемещения запрещены.
- Атак можно делать несколько, пока есть темп.
- Каждая фигура может действовать **не более одного раза за ход**: после её перемещения или атаки её `id` добавляется в `turnMove`, и повторные действия этой фигурой запрещены (`already-moved`).
- Следствие: фигура, которая уже ходила, не может потом атаковать, и наоборот.
- Ходить/атаковать можно только фигурами текущей стороны (`not-your-turn` иначе).
- Движение/атака стоят 1 темп. При 0 темпа нельзя действовать (`no-tempo`).

## 5. Темп (tempo)

- `maxTempo` начинается с 1 и растёт с ходами, максимум 5.
- `turnCount` увеличивается на 1 после окончания хода чёрных (полный раунд).
- Формула: `maxTempo = min(5, floor(turnCount / 2) + 1)`.
- В начале хода текущего игрока его темп устанавливается в `maxTempo` (`setTempo(turn, maxTempo)`).
- Расход: 1 за перемещение, 1 за атаку, `cost` карты за розыгрыш карты.
- Темп не переносится между ходами: в начале нового хода он перезаписывается.
- При 0 темпа нельзя двигаться/атаковать/играть карты дороже 0.

Приблизительная динамика: первые ходы — 1 темп, затем 2, 3, 4, 5 по мере роста `turnCount`.

## 6. HP и исход

- Урон вычитается из `hp` цели.
- Фигура удаляется при `hp <= 0`.
- Лечения/усиления в базовой логике нет, кроме потенциальных эффектов карт.
- **Явного условия победы/поражения в коде нет**: игра не завершается автоматически; король — обычная фигура с HP 6. Цель (если нужна) определяется правилами/сценарием вне кода.

## 7. Карты

### 7.1 Каталог (схема карты)

Карты описываются в `public/assets/cards/cards.json` (или передаются через `setCardCatalog`). Поля:

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный идентификатор. При дубликате id карта пропускается. Если пусто — генерируется из `name`. |
| `name` | string | Название (обязательно, иначе карта пропускается). |
| `text` | string | Описание/эффект для игрока. |
| `cost` | number | Стоимость в темпе. Нормализуется: неотрицательное целое, по умолчанию 1. |
| `copies` | number | Сколько копий кладётся в колоду. По умолчанию 1, минимум 1. |
| `art` | string | Путь к картинке (например `assets/white_pieces/spr_rook_white.png`). Если файла нет — плейсхолдер «?». |
| `target` | string | Тип цели. В текущей логике фактически всегда `'cell'`. |
| `effects` | array | Массив эффектов. **Код сохраняет, но не исполняет** (см. 7.6). |

### 7.2 Колода и рука

- Колода общая для обоих игроков.
- Каждая карта из каталога добавляется `copies` раз.
- Колода перемешивается один раз при создании (`CardState.create`) с детерминированным RNG (seed).
- Начальная раздача: 3 раунда, по одной карте сначала белым, потом чёрным → у каждого по 3 карты (`CARD_HAND_SIZE = 3`).
- Максимум в руке: 6 (`MAX_HAND_SIZE = 6`). Добор не происходит, если рука полна.
- В начале каждого следующего хода (после `END_TURN`) игрок, чей ход начинается, добирает 1 карту, если есть место и колода не пуста.
- Сыгранная карта уходит в сброс (`discard`), не возвращается в колоду.
- При пустой колоде добор не происходит.

### 7.3 Розыгрыш карты

- Играть может только текущая сторона (цвет = `turn`).
- Карта должна быть в руке этого игрока.
- Цель обязательна: целочисленные `col,row` внутри доски (`invalid-target` иначе).
- Стоимость должна быть `<=` текущему темпу (`no-tempo` иначе).
- При успешном розыгрыше: карта удаляется из руки, кладётся в сброс; темп уменьшается на `cost`; генерируется событие `card` с `cardId`, `cardUid`, `color`, `col`, `row`.
- В UI карта разыгрывается перетаскиванием на клетку. Недоступные по темпу карты затемнены (alpha 0.55).
- Карту можно играть в любой момент своего хода, в том числе до/после ходов фигур, пока хватает темпа.

### 7.4 Ограничения отображения

- Название: до ~136 px ширины, шрифт уменьшается с 15 до 9, если не помещается.
- Описание: до 4 строк (`setMaxLines(4)`), ширина ~126 px, шрифт 11.
- Стоимость отображается иконкой темпа + числом.
- Арт: прямоугольник ~134×98.


### 7.6 Эффекты (effects)

- `effects` — массив произвольных объектов. Код сохраняет их в состоянии и в сбросе, но **не исполняет**.
- При разработке новых карт эффекты стоит описывать в `text`, а при необходимости — структурированно в `effects`, чтобы потом реализовать обработчик.
- Рекомендуемые примитивы, согласующиеся с логикой:
  - Цель — клетка (`cell`), на которой может быть фигура или пусто.
  - Влияние на фигуру на клетке: изменение `hp`/`atk`, уничтожение, перемещение, телепорт, обмен позициями.
  - Влияние на темп: `+/- tempo`, возможно изменение `maxTempo`.
  - Влияние на карты: добор, сброс, просмотр/выбор.
  - Массовые эффекты по цвету/типу/ряду/колонке/радиусу.
- Любая механика должна учитывать, что карта разыгрывается только в свой ход и стоит темпа; цель всегда клетка.

## 8. Сетевая игра (кратко)

- Роли: `host` (белые) и `guest` (чёрные). Хост авторитетен: применяет действия и рассылает состояние.
- Гость отправляет действие, ждёт `resolved`/`rejected`.
- Проверка прав: гость может двигать только свои фигуры и играть свои карты, только в свой ход.
- Локальный режим: синхронное применение без сети.

## 9. Состояние и сериализация

- Полное состояние игры сериализуется (`toState`/`fromState`), включая фигуры, темп, счётчик ходов, карты, сброс.
- Это позволяет восстанавливать сессию после перезагрузки и синхронизировать онлайн.

## 10. Рекомендации для генерации новых карт

- Держать `cost` в диапазоне 0–5 (чаще 1–3), так как максимум темпа — 5.
- `copies`: 1–4; суммарный размер колоды влияет на частоту появления карты.
- Текст короткий (до 4 строк), название короткое.
- Всегда указывать `target: "cell"` (движок требует клетку).
- Арт: использовать существующие спрайты из `public/assets/...` или оставить пустым (плейсхолдер).
- Баланс: дорогие карты (3–5) должны давать сильный эффект; дешёвые (1) — небольшой.
- Учитывать, что карты играются за темп, который иначе тратится на ходы/атаки.
- Если эффект не реализован в коде, он должен быть явно описан в `text`, чтобы потом можно было добавить обработчик.
- Примеры путей арта:
  - `assets/white_pieces/spr_pawn_white.png`
  - `assets/white_pieces/spr_knight_white.png`
  - `assets/white_pieces/spr_bishop_white.png`
  - `assets/white_pieces/spr_rook_white.png`
  - `assets/white_pieces/spr_queen_white.png`
  - `assets/white_pieces/spr_king_white.png`
  - и аналогичные `black_pieces`.
